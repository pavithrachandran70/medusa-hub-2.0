**Description:**

Allow customers to select multiple products and compare them side by side. Add a Compare button to product cards and product detail pages. Create a comparison page displaying product images, titles, prices, variants, and availability.

### **Acceptance Criteria**

1. Add a Compare button to each product card.
2. Allow customers to add up to 4 products for comparison.
3. Prevent duplicate products from being added.
4. Display selected products on a dedicated comparison page.
5. Show product image, title, price, variants, and availability.
6. Allow customers to remove individual products from comparison.
7. Provide a Clear All option.
8. Persist comparison selections in browser storage for returning visitors on the same browser.
